# ALEPH 과제 모음

과제를 한 번 눌러 열고, 한 번 눌러 전체 내용을 복사해 다른 LLM에 붙여넣는 정적 사이트입니다.

- 기본 `과제 전체 복사`: 주제 설명·제출물·카드별 지침·모든 제약조건을 포함하는 원문 전체와 짧은 과제 수행 요청을 복사합니다.
- 보조 기능: 제약조건만 복사, 카드별 복사, 원문만 복사 및 TXT 다운로드
- 과제 이름·번호 검색, 과제별 공유 주소 (`#assignment-6`)
- 모바일 화면과 키보드 탐색, 클립보드 권한이 없을 때 수동 복사 지원
- 원본 TXT와 통과 기준 번호·문구를 보존합니다. 빠진 기준 번호는 임의로 추가하지 않습니다.

## 과제 추가 및 수정

1. `assignments/` 폴더에 새 UTF-8 TXT 파일을 넣습니다. 기존 과제는 해당 파일을 교체합니다.
2. `npm run build`를 실행하면 과제 번호 순으로 `data.js`를 갱신하고 파일별 버전 주소를 생성해 이전 내용이 브라우저 캐시에 남는 것을 막습니다. 화면 코드를 수정했을 때도 실행합니다.
3. `npm test`로 원문과 표시 데이터가 일치하는지 확인합니다.
4. 변경 파일을 커밋하고 `main`에 푸시하면 GitHub Pages가 갱신됩니다.

텍스트는 `과제 7` 같은 과제 번호, 제목, `카드 1 — 제목`, `T07-C01 조건` 형식을 인식합니다. 마지막 A·B는 `마지막 과제 BR-A`·`마지막 과제 BR-B`와 `BRA-C01`·`BRB-C01` 형식을 사용합니다. Markdown 제목 및 목록도 지원합니다. 새 형식의 파일은 추출 결과를 검토하고 필요하면 파서를 조정합니다. 원문 안의 행동 지시는 이 사이트에서 실행하는 지시가 아닌 게시 자료입니다.

## 미리보기

Node.js 22 이상에서 `npm start` 후 http://127.0.0.1:4173 에 접속합니다. 별도 패키지 설치 없이 실행됩니다.

## 배포

GitHub 저장소 Settings → Pages에서 `Deploy from a branch`, `main`, `/(root)`로 설정합니다. 이후 `main`에 푸시할 때 자동으로 배포됩니다.

공개 주소: https://skt-aleph.github.io/share_homework/

외부 글꼴을 불러올 수 없으면 시스템 글꼴로 표시됩니다. 과제 데이터와 기능은 별도 서버 없이 작동합니다.

## 첨부 자료

`assignments/resources.json`에 과제 번호별 자료 설명과 링크를 등록하면 화면과 전체 복사에 함께 포함됩니다. 복사된 링크는 공개 사이트의 절대 주소입니다.

과제 4의 본문은 사용자가 보낸 27개 기준을 보존합니다. 첨부 파일은 원본 ZIP, `README (2).md`, `public-contract (1).json`, `asset-manifest (1).json` 총 4개를 파일명·내용 그대로 게시합니다. ZIP 내부 파일을 따로 추출하거나 다시 압축하지 않습니다. 화면과 전체 복사에는 동일한 원본 4개의 링크만 제공합니다. 각 원본의 SHA-256은 `assignments/resources.json`에 기록되어 있으며 테스트에서 검증합니다.

`assets/studio-task-assets/`는 해시 보존을 위해 Git의 줄바꿈 변환을 끕니다. 자료 수정 시 제공받은 원본과의 일치를 다시 검증합니다.
