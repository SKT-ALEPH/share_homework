과제 1

나를 소개하는 한 페이지
계획시간 4~5h
링크 하나로 내가 어떤 사람이고 무엇을 좋아하며 어떤 경험이 있는지 보여주는 개인 사이트. 이력서 양식을 복제하는 것이 아니라, 공개 범위를 직접 정한 나의 한 페이지를 만듭니다.

왜 이걸 하는가
무엇을 공개하고 어떤 근거를 앞에 둘지 직접 정해 첫 공개 결과물을 완성합니다.

제출물
결과물 주소 — 무로그인 공개 화면
소스 주소
짧은 확인 방법 4줄 — 위치 / 3단계 이내 행동 / 통과 모습 / 안 될 때 모습
AI와 나의 판단 3줄 — AI에게 맡긴 일 / 직접 판단한 일 / AI 제안을 따르지 않은 일(없으면 이유)
완주 체크리스트
대상·공개 범위와 근거를 정했습니다.
두 기준 화면과 실제 결함을 검사했습니다.
상호작용을 마우스와 키보드로 확인했습니다.
공개 금지 정보와 비밀값이 없습니다.
짧은 확인법과 AI/본인 판단을 제출합니다.
증거 보관 기준
제출에는 주소·소스·짧은 확인법·AI와 본인 판단만 남깁니다.

카드 1 — 대상과 공개 범위
하는 일
누구에게 무엇을 보여줄지 정하고 공개·비공개 범위를 먼저 나눕니다.

완료 목표 새 시크릿 창에서 열리는 공개 주소와 공개 범위 점검표를 만듭니다.

첫 행동
이 페이지는 누구에게 무엇을 보여 주는지 한 문장으로 씁니다.
공개할 것과 공개하지 않을 것을 각각 3개씩 적고 공개 주소를 만듭니다.
통과 기준
T01-C01 제출한 모든 URL(결과물·소스)은 계정 생성·로그인·인증·초대·비밀번호·OAuth·CAPTCHA 없이 새 시크릿 창에서 열린다.
T01-C03 페이지의 대상과 목적이 한 문장으로 적혀 있다.
T01-C04 공개할 정보가 3개 이상 적혀 있다.
T01-C05 공개하지 않을 정보가 3개 이상 적혀 있다.
막히는 지점과 확인 순서
주소가 다른 브라우저에서 열리지 않습니다.
index.html 위치 확인 → 공개 배포 상태 확인 → 새 시크릿 창에서 재확인
남길 것
공개 주소와 공개 범위 점검표

카드 2 — 말이 아니라 근거
하는 일
강점이나 취향 3개를 상황·행동·결과로 다시 쓰고 공개 가능한 근거를 연결합니다.

완료 목표 소개 3개를 다른 사람이 확인할 수 있는 문장으로 만듭니다.

첫 행동
각 항목을 상황·행동·결과 세 칸으로 나눕니다.
개인정보를 제거한 산출물 또는 결과 문장 한 개를 연결합니다.
통과 기준
T01-C06 강점 또는 취향 3개 각각에 구체적인 상황이 있다.
T01-C07 강점 또는 취향 3개 각각에 학생이 한 행동이 있다.
T01-C08 강점 또는 취향 3개 각각에 관찰 가능한 결과가 있다.
T01-C09 공개 가능한 근거 한 개 이상이 소개 항목과 연결된다.
막히는 지점과 확인 순서
공개할 근거가 부담스럽습니다.
이름·기관·연락처 제거 → 이미지 가림 처리 → 관찰 가능한 결과 문장 사용
남길 것
상황·행동·결과 3개와 근거 1개

카드 3 — 두 화면의 첫인상
하는 일
두 기준 해상도에서 소개·활동·근거가 첫 화면에 함께 보이게 합니다.

완료 목표 1366×768과 1920×1080에서 핵심 내용과 가로 폭을 확인합니다.

첫 행동
두 해상도에서 스크롤 전 핵심 3개를 확인합니다.
가로 넘침과 과도한 빈 공간을 고칩니다.
통과 기준
T01-C10 1366×768의 첫 화면에 소개·활동·근거가 보인다.
T01-C11 1920×1080의 첫 화면에 소개·활동·근거가 보인다.
T01-C12 두 기준 해상도에서 가로 넘침이 0건이다.
막히는 지점과 확인 순서
작은 화면에서 핵심이 잘립니다.
세로 여백 축소 → 이미지 크기 조정 → 본문 최대 폭 확인
남길 것
두 해상도 검사 결과

카드 4 — 실제 결함 세 개
하는 일
링크·키보드·제목·명암·콘솔을 검사하고 실제 결함을 고칩니다.

완료 목표 결함 3개 이상의 수정 전후와 최종 콘솔 상태를 남깁니다.

첫 행동
링크와 Tab 이동, 제목 순서, 명암, 콘솔을 검사합니다.
발견한 결함을 하나씩 고치고 같은 검사를 다시 실행합니다.
통과 기준
T01-C13 공개 화면의 모든 링크가 선언한 주소로 열린다.
T01-C14 공개 화면의 주요 기능을 Tab 키로 순서대로 이동할 수 있다.
T01-C15 공개 화면의 제목 단계가 건너뛰지 않는 구조다.
T01-C16 공개 화면의 텍스트 대비율이 일반 글자 4.5:1 이상이고 24px 이상 또는 18.66px 이상 굵은 글자는 3:1 이상이다.
T01-C17 검사에서 발견한 실제 결함 3개 이상에 대해, 제출문에 각각 수정 전 상태와 수정 후 상태가 적혀 있다.
T01-C18 최종 공개 화면의 브라우저 콘솔 빨간 오류가 0건이다.
막히는 지점과 확인 순서
결함을 찾기 어렵습니다.
키보드 초점 확인 → 모든 링크 확인 → 첫 콘솔 오류부터 확인
남길 것
결함 3개의 수정 전후와 콘솔 결과

카드 5 — 나와 연결된 상호작용
하는 일
페이지 내용과 관련된 상호작용 한 개를 접근 가능하게 만듭니다.

완료 목표 마우스와 키보드에서 같은 동작을 하고 움직임 선택권을 제공합니다.

첫 행동
소개 항목 하나와 연결된 펼치기·바꾸기 같은 행동을 정합니다.
클릭·Enter·Space와 움직임 줄이기를 확인하고 비밀값을 검색합니다.
통과 기준
T01-C19 페이지 내용과 관련된 상호작용이 한 개 이상 있다.
T01-C20 그 상호작용은 마우스로 실행된다.
T01-C21 그 상호작용은 키보드로 실행된다.
T01-C22 큰 움직임이 있으면 사용자가 줄이거나 끌 수 있다.
T01-C23 공개하지 않기로 한 개인정보가 페이지와 제출물에 0건이다.
T01-C24 비밀번호·토큰·API 키 원문이 페이지·배포 파일·Git 기록·제출물에 0건이다.
T01-C25 짧은 확인 방법에 ① 어디로 가나요, ② 3단계 이내 무엇을 하나요, ③ 무엇이 보이면 통과인가요, ④ 안 될 때 무엇이 보이나요가 구분되어 있다.
T01-C26 제출문에 ① AI에게 맡긴 일, ② 학생이 직접 판단한 일, ③ AI 제안을 따르지 않은 일(없으면 없었던 이유)이 구분되어 있다.
막히는 지점과 확인 순서
키보드로 실행되지 않습니다.
button 요소 확인 → Tab 초점 확인 → Enter와 Space 검사
남길 것
상호작용·움직임 선택·비밀값 점검
